## Research and alternatives

- [npm trusted publishing](https://docs.npmjs.com/trusted-publishers/) supports
  an exact GitHub Actions workflow and OIDC after package creation. The
  workflow’s short-lived token fallback is the viable first-publication path;
  it needs operator-controlled npm authorization.
- [Rust `link-cli`](https://github.com/link-foundation/link-cli) provides the
  required LiNo import/export, automatic references and transaction options.
  The current use preserves exact export verification. Switching to an
  unrelated datastore would violate the binary round-trip requirement;
  chunked verified imports or an upstream performance fix are candidates.
- [mtcute storage guidance](https://mtcute.dev/guide/topics/storage) describes
  native session storage. The existing GramJS string session is suitable as an
  external test driver, not a production mtcute credential.
- The browser alternatives are verified product-detail navigation or an
  explicit source replacement/disable policy. A challenged page is never
  counted as parsed, and CAPTCHA bypass is excluded.
