## Research and design choices

- Node exposes an engine-dependent [maximum string length](https://nodejs.org/api/buffer.html#bufferconstantsmax_string_length). The retained 1.295-billion-character LiNo estimate exceeds that limit before `saveOffers` can compare its 10 GiB ceiling. `links-notation` provides a whole-document [`formatLinks`](https://github.com/link-foundation/links-notation) API; neither it nor `clink` supplies an application-level atomic offer collection. The selected design partitions typed schema-v3 LiNo by offer-id hash into bounded, content-addressed files, each verified by the existing exact `clink` projection. A single compact JSON blob would be shorter, but would abandon addressable typed links; truncating or relaxing export verification would hide data loss.
- [npm trusted publishing](https://docs.npmjs.com/trusted-publishers/) uses GitHub Actions OIDC and can publish provenance, but the repository's unpublished package still needs the owner's bootstrap token under its current release workflow. [Docker `imagetools inspect`](https://docs.docker.com/reference/cli/docker/buildx/imagetools/inspect/) can verify the combined index and each required architecture digest. No token, Docker repository variable, or immutable artifact was supplied here.
- [mtcute's native session export/import](https://mtcute.dev/guide/topics/storage) is supported. Its session string is an account credential. The native runtime user must log in independently; the existing GramJS observer session is kept distinct. The existing manual harnesses implement this boundary.
