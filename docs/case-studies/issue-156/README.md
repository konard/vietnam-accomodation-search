## Reproduction, measurements and implementation

Before the change, three unit tests fail because the bootstrap URL and helper requests are unversioned. Root `command-stream: 1.3.0` did not pin `await use('command-stream')` in release scripts. The shared loader now requests `command-stream@1.3.0`, `lino-arguments@0.3.0` and use-m 8.16.4, verifies SHA-256 `6cc5be008885fd2ee1f4eec0482652c4162f5d6d9703efa5116edd270d6b63f9`, streams at most 1 MiB, alternates immutable unpkg/jsDelivr mirrors, and bounds both each attempt and the complete retry budget. Caller abort interrupts response-body reads and backoff; late bytes cannot be evaluated after cancellation. Non-default injected policies cannot reuse the default cache.

The regression suite includes tampered bytes, oversized streaming bodies, stalled bodies ignoring the fetch signal, caller cancellation before/during work, and stalled retry backoff. The Windows integration skip was removed after inspecting the pinned loader's `pathToFileURL` implementation; an integrity failure cannot be mistaken for an offline skip. All script consumers continue through the shared loader/adoption guards. Package manifest and root lockfile are unchanged; no latest-major dependency or new PTY was introduced.
